Lucius AI

Enterprise browser-automation SaaS. Operated cloud infrastructure across AWS EKS and DigitalOcean Kubernetes for 30+ services.

AWS EKSDOKSTerraformArgo CDVault
Read the engineering summary ＋

Challenge: Isolated browser workloads can create unpredictable resource demand and infrastructure cost.

Approach: Operated Kubernetes clusters on AWS EKS and DigitalOcean Kubernetes; partnered with developers on resource requests and limits, autoscaling, environment parity, GitOps delivery with Argo CD, and centralized observability using Prometheus, Grafana, and Loki. Vault and External Secrets Operator supported secrets management.

Outcome: CV-reported 40% higher concurrent test capacity, 25% lower environment cost, and 40% lower mean time to detect issues.

PlatformPilot

A Go-based platform engineering lab exploring Kubernetes integration and application operations through an API.

Goclient-goKubernetesDocker
Find repositories on GitHub ↗
Read the engineering summary ＋

Goal: Explore how a Go service can interact with a Kubernetes cluster and expose application operations through a small API.

Implementation: Built an HTTP API in Go and integrated Kubernetes using client-go. Tested locally with Docker and a Kind cluster, created a dedicated namespace, and deployed workloads for API-based inspection.

What it demonstrates: Go service structure, Kubernetes API integration, containerized development, and a foundation for platform-engineering features such as workload status and operational visibility.

Project status: Personal engineering lab; features and scope may evolve. Browse the GitHub profile ↗ for the repository when public.
