# Jisna C John — Engineering Portfolio

A lightweight, static portfolio for cloud, platform, DevOps, and AI/ML infrastructure engineering.

## Pages
- `index.html` — professional portfolio: profile, engineering capabilities, measured impact, project case studies, writing, experience, CKA certification, and contact.
- `game.html` — optional Cloud Hopper mini-game. It is intentionally separate from the main portfolio flow.

## Key files
- `styles.css` — portfolio styles.
- `script.js` — terminal and responsive navigation interactions.
- `cloud-hopper.css` / `cloud-hopper.js` — isolated game presentation and browser-only game logic.
- `assets/jisna-profile.webp` — optimized profile image (under 100 KB).
- `assets/favicon.svg` — site icon.
- `resume.pdf` — downloadable resume.
- `projects/llm-on-kubernetes/README.md` — scope and security focus for the in-progress LLM-on-Kubernetes engineering lab.

## Run locally
Open `index.html` in a browser. Open `game.html` to play Cloud Hopper. No backend, API keys, or paid services are required.

## Deploy with GitHub Pages
Push the repository contents to GitHub and enable GitHub Pages in repository settings.
