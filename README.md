# Jisna C John — DevOps Portfolio

A responsive, dark terminal-inspired portfolio built with plain HTML, CSS, and JavaScript.

## Cost
This project has no backend, no paid API, and no build step. It can be hosted free on GitHub Pages.
The Google Fonts import is optional; the site falls back to system fonts if unavailable.

## Publish on GitHub Pages
1. Create a **public** GitHub repository named `johnjisna.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets/` directory to the repository root.
3. Commit the changes to the `main` branch.
4. Open **Settings → Pages** and set the source to **Deploy from a branch**, choose `main` and `/(root)`, then Save.
5. Wait for the Pages deployment to complete. Your URL should be `https://johnjisna.github.io/`.

Alternatively, use the GitHub Pages workflow offered in repository settings.

## Before publishing
- Verify every metric and experience statement.
- Add a direct link to your public PlatformPilot repository if/when available.
- If you want a CV download button, place a PDF named `resume.pdf` in the repository root and add a link to it.
- Keep professional project details high-level and do not publish confidential architecture, credentials, hostnames, or customer data.
- Certification is listed as stated in the CV. Add a credential verification link only if you have one.
- Replace any wording that no longer reflects your current CV.
